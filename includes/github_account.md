!!! note "Add your GitHub account to this computer (while MPM3S.jl is private)"
    MPM3S.jl is private for now, so downloading it needs a GitHub account with access to
    [MPM3S.jl](https://github.com/MPM3S/MPM3S.jl), and a token that this computer uses in place of your GitHub password.
    This note disappears when MPM3S.jl is made public. To make the token:

    1. On GitHub, go to **Settings → Developer settings → Personal access tokens → Tokens (classic)** and click
       **Generate new token (classic)**.
    2. Tick **`repo`** to download the code with `git` (the Julia pages), or **`read:packages`** to download the
       container image (the container pages); tick both to use one token for both. Choose an expiry date and generate
       the token.
    3. Copy the token and keep it as safe as a password: GitHub shows it only once.
