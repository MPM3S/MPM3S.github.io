MPM3S.jl is private for now, so downloading it needs a GitHub account with access to
[MPM3S.jl](https://github.com/MPM3S/MPM3S.jl), and a token to use in place of your GitHub password. This note
disappears when MPM3S.jl is made public. To make the token:

1. Open [github.com/settings/tokens](https://github.com/settings/tokens) (on GitHub: **Settings → Developer settings →
   Personal access tokens → Tokens (classic)**) and click **Generate new token (classic)**.
2. Tick **`repo`** and **`read:packages`**, choose an expiry date and generate the token.
3. Copy the token and keep it as safe as a password: GitHub shows it only once.
