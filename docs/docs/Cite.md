# Cite this work

If you use MPM3S in your work, please cite the version you used:

> Bird, R. E., Coombs, W. M., Augarde, C. E. and Finnigan, S. *MPM3S* (v0.4.3) [Computer software].
> Durham University. <https://github.com/MPM3S/MPM3S.jl>

Change `v0.4.3` to your version: it is at the top of the README in your copy of MPM3S.

## Citation file

The citation details are in [CITATION.cff](https://github.com/MPM3S/MPM3S.jl/blob/master/CITATION.cff)
on MPM3S.jl. Each release updates its version and release date.

On the [MPM3S.jl page](https://github.com/MPM3S/MPM3S.jl), **Cite this repository** in the right-hand
sidebar gives the latest release's citation as APA or BibTeX, ready to copy.

## BibTeX

```bibtex
@software{MPM3S,
  author    = {Bird, Robert E. and Coombs, Will M. and Augarde, Charles E. and Finnigan, Samantha},
  title     = {{MPM3S}},
  version   = {0.4.3},
  year      = {2026},
  publisher = {Durham University},
  url       = {https://github.com/MPM3S/MPM3S.jl},
  license   = {GPL-3.0-only}
}
```
