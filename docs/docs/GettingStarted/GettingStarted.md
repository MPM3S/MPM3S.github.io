# Overview

## Installation and setup
S3-MPM is written in Julia and can run on CPU or GPU (NVIDIA) machines.

To get up and running with S3-MPM, first go to the **[Install and Run](install_and_run.md)** page.

The page contains the system requirements, installation instructions for different operating systems, containers and cloud computing services.

It is also provides the command lines for running an analysis.

## Tutorial problems
Once installed, head to the **[Tutorial problems](../TutorialProblems/TutorialProblems.md)** section for a hands-on walkthrough of your first S3-MPM analysis.
