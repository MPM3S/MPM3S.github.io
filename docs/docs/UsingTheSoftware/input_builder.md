# Interactive builder

Build an `input_data.json` file in your browser. Start from a tutorial's file or a blank one, or load your own, then change it in the form: keys that do not apply are hidden, optional keys are switched on with their tick box, and the file on the right updates as you type. When the status bar is green, download the file and run it as in [install and run](../GettingStarted/install_and_run.md).

Each key's box is coloured by its status, as on the [reference pages](InputFormat/index.md#how-to-read-these-pages): <span class="ib-legend ib-st-R">required</span> <span class="ib-legend ib-st-C">required in this situation</span> <span class="ib-legend ib-st-O">optional</span>. Click an issue to jump to its key.
