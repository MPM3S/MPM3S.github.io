    Self-weight column - input_data_gravity_column.json¶

    The complete input_data_gravity_column.json for Tutorial 1, also included with MPM3S in validation_data_and_jsons. Every key is described on the input_data.json file format page. Click the numbers in the file to see what each part does, with links to the tutorial's explanation and to the format reference for those keys.

    {
    "GPU": "off", // (1)!

    "domain update": "stretch", // (2)!

    "domain": { // (3)!
        "gravity": [0.0, 0.0, -9.81]
    },

    "material points": { // (4)!
        "extra capacity": 1.2,
        "element size": 0.05,
        "number of material points per element 1": 2,
        "material size": { "min": [0.0, 0.0], "max": [0.05, 0.05] },
        "layers": [
            {
                "thickness": 0.8,
                "material": { "type": "elastic", "E": 1.0e4, "nu": 0.0, "density": 50.0 }
            }
        ]
    },

    "rigid bodies": [], // (5)!

    "contact": { // (6)!
        "friction coefficient": 0.0
    },

    "analysis": [ // (7)!
        {
            "type": "static",
            "load steps": 50,
            "load": "gravity ramp",
            "rigid bodies": "off",
            "boundary conditions": { "min": ["roller", "roller", "fixed"], "max": ["roller", "roller", "free"] }
        }
    ],

    "solver": { // (8)!
        "tolerance": 1.0e-6,
        "max newton iterations": 20,
        "poor factor": 0.25,
        "ghost factor": 0.0,
        "ghost factor mass": 0.0
    },

    "output": { // (9)!
        "vtk": "on",
        "vtk directory": "vtk_column",
        "vtk percent": 0,
        "vtk material point fields": ["displacement", "stress", "strain", "volume"],

        "csv": "on",
        "csv directory": "csv_column",
        "csv percent": 0,
        "csv material point fields": ["initial position", "position", "stress"],
        "csv rigid body fields": []
    }
}
    1. Runs on the CPU, which is plenty for a problem this small. Machine → · GPU →
    2. Lets the GIMP domains near the base shrink as the column is compressed. Machine → · Domain update →
    3. Gravity in \(-z\); the background mesh is sized automatically to hold the column. Domain → · Domain →
    4. One \(0.8\) m elastic layer on a \(0.05 \times 0.05\) m footprint: \(0.05\) m elements, each with \(2 \times 2 \times 2\) GIMPs. Material points → · Material points →
    5. There are no rigid bodies. Rigid bodies and contact → · Rigid bodies →
    6. Required even with no bodies; it has no effect here. Rigid bodies and contact → · Contact →
    7. One static stage: gravity ramped up over 50 load steps, rollers on the sides, a fixed base and a free top. Analysis → · Analysis stages →
    8. Tolerance \(10^{-6}\) and 20 iterations; ghost stabilisation is off, as the column fills its elements. Solver → · Solver →
    9. VTK and CSV files at every load step. Output → · Output →
