    Common tasks¶

    Every MPM3S analysis is set up by one input_data.json file with nine top-level sections: "GPU", "domain update", "domain", "material points", "rigid bodies", "contact", "analysis", "solver" and "output". Find what you want to do below; each row names the keys, links to their reference and to a tutorial that does it.

    The soil¶

    I want to... Keys Reference Example
    Set the soil block's size and mesh "element size", "material size", "number of material points per element 1" Material points Tutorial 1
    Use more than one soil layer "layers", one entry per layer, top to bottom Material points -
    Choose a material model "material" → "type" Material models Tutorial 3
    Make the stiffness grow with depth "E overburden" Stress-dependent stiffness Tutorial 3, 6
    Let material points shrink as the soil compresses "domain update": "stretch" Domain update Tutorial 1, 2
    Set up the initial stresses a static stage with "load": "gravity ramp" Analysis stages Tutorial 1, 3, 6
    Model a slope on a level grid tilt "gravity" Domain Tutorial 5
    Hold the sides and base "boundary conditions" in each stage Boundary conditions every tutorial

    Rigid bodies¶

    I want to... Keys Reference Example
    Add a structure from an STL file a point, and "stl files" welded to it STL files Tutorial 2
    Push a body a set distance each step the point's "boundary conditions": {"prescribed": q} Points Tutorial 2
    Hold a body still, then move it in a later stage "rigid body boundary conditions" in that stage Rigid body boundary conditions Tutorial 3, 6
    Start a body exactly on the soil surface "rigid body surface placement": "on" Analysis stages Tutorial 2, 3, 5, 6
    Let a body move freely under gravity "free" point boundary conditions, a dynamic stage Points Tutorial 5
    Join bodies with a hinge, a rod or an angle stop "constraints" How the constraints work Tutorial 6
    Add friction between soil and bodies "contact" → "friction coefficient" Contact Tutorial 3, 5, 6
    Follow a point on a body, such as a fluke tip "tracked nodes" Tracked nodes Tutorial 6

    The mesh and the stages¶

    I want to... Keys Reference Example
    Refine the mesh around a body as it moves "adaptivity": {"type": "rigid body surface"} Adaptivity Tutorial 3, 5, 6
    Mesh the whole domain at the base size "adaptivity": {"type": "uniform"} Adaptivity Tutorial 2
    Model a long drag without meshing all the soil "boundary track" Boundary track Tutorial 5, 6
    Include inertia a "dynamic" stage: "dt", "final time", "beta", "gamma" Analysis stages Tutorial 5, 6
    Run on a GPU "GPU": "on" GPU Tutorial 3, 6

    Results¶

    I want to... Keys Reference Example
    See the soil and bodies in ParaView "vtk": "on" and its fields Output every tutorial
    Get the stresses at the material points "csv material point fields" Field names Tutorial 1
    Get the force on a body "csv rigid body fields": "reaction force" Output files Tutorial 2, 3, 6

    Run the file with MPM3S.non_linear_solve("input_data.json") - see install and run.

    Conventions and key statuses

    SI units; angles in degrees; tension positive; vectors [x, y, z] with \(z\) vertical; all positions in one global frame; switches "on" / "off" (the boundary track's "remove" takes "yes" / "no"); systems and points numbered from 1.

    On the reference pages, required keys must be present (a missing one stops the analysis and names the key), optional keys fall back to their default, conditional keys are required only as stated, and ignored keys are never read.
